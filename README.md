## 离线字典暴力破解

**破解速度取决于字典的质量**

1. macOS 自带 **嗅探工具** 可以抓取到无线网络的数据包
    - 这里主要是为了抓取**WPA四次握手**报文，该报文本身不包含密码，是一个加密后的报文
    - 通过这个报文，我们可以离线根据字典中的密码进行破解
2. 通过安装aircrack-ng工具破解
    - 安装命令: `brew install aircrack-ng`
    - 破解命令: `aircrack-ng -w 字典路径 pcap文件路径`

理论上来说，WiFi密码的长度在8-63个字符之间，包含数字、字母和特殊字符。
实际上一般密码长度不长，而且不复杂，可以编写程序，也可以通过已有字典进行破解。
